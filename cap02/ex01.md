# 01 Suponha que você esteja criando um aplicativo para acompanhar suas finanças 
# 1. Compras 2. Cinema 3. Mensalidade da academia
# Todos os dias você anotará tudo o que gastou e onde gastou. No final do mês, você deverá revisar os seus gastos e resumir o quanto gastou. Logo, você terá um monte de inserções e poucas leituras. Você deverá usar um array ou uma lista para implementar este aplicativo?

Para inserções o melhor são listas porque é O(1).
Para leitura arrays são melhores porque é O(1).

Já que no aplicativo será utilizado muitas inserções e poucas leituras, o melhor a ser feito é utilizar uma lista encadeada.
